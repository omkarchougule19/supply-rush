# Workspace Rules for AI Agents

When working on the **Capacity Planning Game (Supply Rush)** project, all AI coding assistants must adhere to the following rules:

1. **Read Rules & Specifications First:** Before making any code changes, analyzing the repository, or executing any tasks, you MUST read the comprehensive game specifications, constants, and rules defined in [rules.txt](../rules.txt).
2. **Do Not Violate Core Mechanics:** Ensure that no proposed or implemented changes violate any of the established game rules, warehouse/vehicle specifications, service radius logic, or quarter progression loops documented in [rules.txt](../rules.txt).
3. **Document Decisions and Thinking:** Any time you implement a new feature, fix a bug, or adjust game parameters, you MUST document your design decisions, the ideas behind the change, and the exact implementation steps in [rules.txt](../rules.txt) under the developer log section (`## 7. Development Log: Ideas & Implementation Steps`).
